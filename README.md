# RentCan - Property Management Made Simple

RentCan is a modern, lightweight landing page and property management interface designed for the Tricity area. It showcases a premium user experience with dynamic video backgrounds, smooth animations, and a seamless flow for both landlords and tenants.

## Features
- **Cinematic UI**: Auto-playing background videos with fallback optimizations.
- **Lightning Fast**: All bulky media assets are separated and served via a global Content Delivery Network (CDN) (`jsdelivr`).
- **Fully Modular**: Clean HTML structure with external, minified CSS and Javascript.
- **Backend-Free Simulation**: Includes a mocked authentication layer to simulate Supabase OTP logins instantly without requiring a database.
